# 布果果 / Khada：固定左右视 + MP4 改名

油猴脚本：在 [3d.buguoguo.cn](https://3d.buguoguo.cn) 模型预览页锁定侧面视角，并把导出的 MP4 改成 `champion_skin_animation.mp4`。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox）。
2. 打开 Tampermonkey 仪表盘 → **添加新脚本**（或编辑已有脚本）。
3. 粘贴 [`buguoguo-view-export.user.js`](./buguoguo-view-export.user.js) 全文，确认头里是 `@version 1.7.0`，保存。
4. **建议**：先只启用这一条脚本，其它油猴脚本先关掉，避免互相干扰。
5. 打开预览页：`https://3d.buguoguo.cn/model-viewer?id=518000`  
   等 3D 画布出来后，左上角应出现 **SpriteArt 导出助手**（`v1.7`）。

若左上角出现红字「未能注入页面」，或根本没有面板：在 Tampermonkey 删除旧脚本后重新添加 v1.7.0，Ctrl+F5；并暂时关掉其它油猴/广告拦截。

若网页一直转圈：先禁用本脚本确认站点本身可开，再只启用这一条重试。

## 使用

| 功能 | 说明 |
|------|------|
| **右视** | 水平侧视，角色面向画面右侧（可复现） |
| **左视** | 对称的另一侧 |
| **导出 MP4** | 自动展开站点「导出」并点击「导出为 .mp4」 |
| **文件名预览** | 随当前英雄 / 皮肤 / 状态机更新；下载时自动改名 |

然后照常在站点右侧 **导出 → 导出为 .mp4**。下载文件名会变成例如：

```text
neeko_base_idle1.mp4
```

命名规则：

- `champion`：画布 `data-alias`（如 `neeko`）
- `skin`：皮肤 id 整千为 `base`，否则优先用动作名后缀 / `skin{编号}`
- `animation`：当前状态下拉框文本，去掉 `_Base` 后清洗为小写蛇形

## 范围

只做这两件事，**不会**自动关阴影/水印、不会改绿幕、不会批量录制。

## 故障排查

- 提示「未找到相机控件」：刷新页面，等模型转完再点；确认地址是 `/model-viewer?id=…`。
- 左右视反了：跟我说一声，把方位角对调即可。
- 文件名不对：看面板上的预览是否已是目标名；动作切换后预览会刷新。
- 站点大改版后可能失效：把浏览器控制台报错发我即可再适配。
